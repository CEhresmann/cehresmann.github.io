Pet-проекты

Чат-приложение на микросервисах

В рамках учебного проекта реализовал чат-приложение из двух микросервисов — аутентификации пользователей и обмена сообщениями. Микросервис аутентификации реализован с использованием gRPC для обработки запросов на регистрацию и вход, для сериализации данных пользователей использовался Protocol Buffers. Метрики производительности собирались через Prometheus, для их визуализации использовалась Grafana.
